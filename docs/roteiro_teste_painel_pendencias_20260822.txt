ROTEIRO DE TESTE — PAINEL DE PENDÊNCIAS POR MÓDULO
Projeto: Green Portal
Data: 22/08/2026
Arquivo principal: principal/painel_pendencias.php
Arquivos relacionados: principal/main.php, principal/main_pendencias.php

1. OBJETIVO

Validar se o painel de Pendências apresenta cards por módulo, respeita as
permissões do usuário, mostra somente pendências associadas ao usuário logado
e abre o grid correspondente com os filtros corretos.

2. PRÉ-REQUISITOS

- Ambiente de desenvolvimento disponível.
- Banco tenant Modelo acessível.
- Usuário administrador disponível para o teste completo.
- Usuário comum com acesso parcial a módulos.
- Usuário sem acesso ao módulo de Não Conformidades.
- Navegador com cache atualizado.
- Sessão autenticada no Green Portal.

3. TESTE DE ACESSO AO PAINEL

Passos:

1. Acessar o Green Portal.
2. Confirmar que o menu lateral direito foi carregado.
3. Clicar no ícone Pendências.

Resultado esperado:

- Deve abrir uma aba chamada Pendências no workspace principal.
- A tela deve ser `painel_pendencias.php`.
- A tela deve apresentar cards dos módulos permitidos.
- Não deve abrir diretamente `naoconformidades_minhasocorrencias.php`.
- O painel não deve apresentar erro PHP ou tela em branco.

14. CRITÉRIOS DE APROVAÇÃO

O teste será considerado aprovado quando:

- O ícone Pendências abrir primeiro o painel de cards.
- Os cards forem exibidos conforme as permissões.
- Cada card abrir o grid ou painel correto.
- Os filtros limitarem os resultados ao usuário e às pendências.
- O card de NC e o grid apresentarem a mesma quantidade.
- Não houver acesso indevido a dados de outros usuários.
- Não houver erro de PHP, SQL ou JavaScript.
